AI Policy
=========

Generally, AI should be used to make us better programmers. In that spirit, AI is allowed in this
project for things that contribute to building a healthy environment for self-development and
good engineering.

AI tools can be used for research, learning, debugging, reviewing code, identifying better
techniques, or potential optimization opportunities.

AI tools can be used locally for development purposes, such as generating quick scripts to explore
ideas, harnesses for profiling, benchmarking, tests, data analysis, etc, provided that the code is
not submitted to the repo.

Contributions must not contain legally significant AI-generated code or content. All contributors
are responsible for their submitted changes, and should be able to explain every line they've
submitted (without AI!).

This project does not provide an `AGENTS.md` file on purpose in order to discourage vibe coding.
Instead, I would like to encourage the wider programming community to either use AI wisely -- or not
at all.
